# 单课学习记录模板

复制本模板填写；模板中的待填项不代表任务已经完成。[进度总表](../PROGRESS.md)

## 基本信息

| 字段 | 记录 |
|---|---|
| 课程编号、名称 | 待填 |
| 日期、学习者 | 待填 |
| 当前状态 | 未开始 / 学习中 / 已实操 / 已验收 / 待复习 |
| 源码提交、工作区未提交改动 | 待填 |
| 操作位置 | Windows / NUC / 仿真 / 离线数据 |
| 本次小目标 | 用一句可验证的话描述 |

## 理解与操作

- 涉及文件、包、节点和入口：
- 输入、处理过程、输出与下游：
- 操作前预测会看到什么：
- 实际执行命令及所在终端/目录：
- 输出、日志、截图或录包位置：
- 与预测不一致之处：
- 我对差异的解释及依据：

## 验收

- 本课路线图的完成标准：
- 我可以脱离提示独立完成的操作：
- 我可以用自己的话解释的内容：
- 尚不能回答的问题：
- 验收结论、日期、依据：

## 续接

- 需要保留的配置/数据/布局及路径：
- 做过的临时改动和恢复结果：
- 下次复习题：
- 下一步课程与起点：

只有完成练习且保留证据才能记为“已实操”；有独立解释或操作证据才记为“已验收”。纯源码阅读课用文件定位、调用链图和作答作为证据。
