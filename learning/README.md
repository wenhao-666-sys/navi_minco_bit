# navi_minco_bit 学习入口

这套材料面向已经会运行 ROS 项目、用过 RViz 的学习者，以 Ubuntu 22.04 / ROS 2 Humble、NUC、双 MID-360 和轮式底盘为实践平台。

## 从这里开始

1. 查看 [完整路线图](ROADMAP.md)，了解 A、B、C、O 四组共 33 个课程单元。
2. 打开 [A01：项目总览与文件结构](lessons/A01_PROJECT_OVERVIEW.md)，完成本课三个定位问题。
3. 使用 [全文件索引](PROJECT_INDEX.md) 查找源文件、所属包和阅读入口。
4. 将操作、问题和证据更新到 [学习进度](PROGRESS.md)。

当前 A01 教材已准备；用户掌握情况尚待回答与操作验证。NUC 构建、Foxglove 连接、仿真和实机运行均未在本次文档工作中执行。

## 后续如何继续教学

可以直接发送“继续 A01”或“继续上次课程”。续接时先读进度表及最近一条记录，再检查当前源码版本；每次只推进一个能验证的小目标。

课堂固定流程：说明目标 → 建立输入输出图景 → 定位生效文件 → 预测现象 → 操作验证 → 解释差异 → 用户复述或独立操作 → 更新记录。

教材中的配置结论对应记录的源码基线。源码更新后，先核对入口与接口变化，再沿课程继续；把真实操作结果补进进度表，保留失败案例和解释。
